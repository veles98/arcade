واستخدمها كل مرة. كيف أركّب السكيل؟ 3 خطوات، وخلاص.

  1. حمّل السكيل.

    اضغط «حمّل السكيل» وخذ ملف ZIP.

  2. جهّز Claude.

    افتح Settings ← Capabilities، وشغّل Code execution and file creation.

  3. ارفعه. وخله يشتغل.

    افتح claude.ai/customize/skills، اضغط Add ثم Upload skill، وارفع الملف. يشتغل لحاله لما تطلب شي يناسبه.

يشتغل حتى بالحساب المجاني. السكيلات اللي عليها «Claude Code»: فك الضغط داخل ~/.claude/skills/.
