# صرّخ! (Sarrikh)

لعبة جوال تتحكم فيها بصوتك: تكلم أو دندن يمشي الكائن، صرّخ ينط، وكل ما ارتفع الصوت ارتفعت النطة.

- ملف واحد: `index.html` (JavaScript عادي، بدون مكتبات، خط Alexandria من Google Fonts).
- الأوضاع: «العب مع خويك» (سوا: صوت المجموعة كلها يشغّل النطة بعتبة أعلى / بالدور: كل لاعب جولة ثم لوحة نتائج وجملة طقطقة على الخسران) و«لحالك».
- المايك: Web Audio AnalyserNode، RMS مع تنعيم، ومعايرة ثانيتين للهدوء قبل كل لعبة. الصوت ما يطلع من الجوال ولا يتسجل.
- بدون مايك أو لو رُفض الإذن: رسالة عربية واضحة + وضع اللمس (يمشي تلقائيًا، اضغط مطوّل عشان تنط).
- صورة النتيجة 1080x1920 مع @anas.ai.ar عبر Web Share أو تنزيل.
- الشكل: ألوان حية (سماء، تلال بطبقات، عشب)، بطل ملوّن بتظليل وفم ينفتح مع الصوت، لون لكل لاعب، كونفيتي، حلقة صرخة، عدّاد إزعاج أخضر/أصفر/أحمر.
- الصوت كله مولّد بـ WebAudio (بدون ملفات، بدون رخص): موسيقى خفيفة تنخفض وقت الصراخ، خطوات، نطة «بوينغ» حدتها تزيد مع الصوت، هبوط، عملة، صوت لكل عائق (قطة، بطة، صحون، لوحة، أصيص)، صفارة سقوط + «سبلاش»، فانفير كومبو/رقم قياسي، نقرات، عدّاد المعايرة، طبول وكشف النتيجة، وضحكة جمهور مولّدة على جملة الطقطقة. زر كتم في القائمة يُحفظ في localStorage.
- اهتزاز عبر navigator.vibrate لو مدعوم.

## تجربة محلية
```
python -m http.server 8765
```
افتح http://localhost:8765/ (المايك يشتغل على localhost وعلى HTTPS فقط).

روابط الاختبار: `?fake` يخلي قوة الصوت تجي من `window.__fakeLevel` (0..1)، `?capture` يوقف الحلقة ويخلي الإطارات تمشي بـ `window.__step(dt)`، `?seed=N` يثبت العشوائية. في وضع `?capture` الأصوات تتسجل كأحداث وتتحوّل لملف WAV عبر `window.__renderAudio(sec)` (OfflineAudioContext) لتصوير المقاطع.

ملاحظة: «ديسيبل تقريبًا» رقم نسبي فوق هدوء المكان، مو مقياس صوت معاير.
