برومبت واحد = لعبة جوال كاملة

غيّر [فكرة اللعبة] بس، واحفظ الناتج باسم game.html وافتحه من جوالك.

أنت مطوّر ألعاب جوال محترف. سوّ لي لعبة جوال كاملة وجاهزة في ملف HTML واحد.

فكرة اللعبة: [فكرة اللعبة]

الشروط (لازم كلها):
1) ملف واحد فقط فيه HTML و CSS و JavaScript. بدون أي مكتبة أو صورة أو ملف أو خط خارجي. كل الرسوم ترسمها بالكود على <canvas> (أشكال وتدرّجات)، ولا تستخدم الإيموجي كشخصيات.
2) للجوال بالطول: الكانفس يملأ الشاشة ويتكيّف مع أي مقاس ومع دقة الشاشة (devicePixelRatio) ومع تغيّر حجم النافذة. حط:
   <meta name="viewport" content="width=device-width,initial-scale=1,maximum-scale=1,user-scalable=no">
   وامنع السحب والتكبير والتحديد (touch-action:none; user-select:none; overflow:hidden).
3) التحكم باللمس: لمسة وحدة، أو لمس نص الشاشة اليمين/اليسار لو الفكرة تحتاج اتجاهين. استخدم pointerdown على الشاشة كلها مع preventDefault، واللمسة تستجيب فورًا. ويشتغل بعد بالماوس، وبالمسافة والأسهم في الكمبيوتر.
4) ثلاث شاشات واضحة:
   - البداية: اسم اللعبة + طريقة اللعب بسطر واحد + زر كبير «ابدأ».
   - اللعب.
   - النهاية: النتيجة + أفضل نتيجة + زر «العب مرة ثانية» (يتفعّل بعد 0.6 ثانية عشان ما ينضغط بالغلط) ويرجّع كل شي من الصفر بدون تحديث الصفحة.
5) النقاط: تظهر فوق طول اللعب وتكبر حركة صغيرة لما تزيد. أفضل نتيجة تنحفظ في localStorage داخل try/catch (ولو التخزين ممنوع احفظها في متغير بدون ما تطلع خطأ)، واكتب «رقم قياسي جديد!» لما تنكسر.
6) صعوبة عادلة: أول 5 ثواني سهلة جدًا، بعدها تسرع شوي شوي لحد سقف معقول. أي عائق لازم يكون ممكن تفاديه دائمًا، واحسبها بالوقت مو بالعين: الوقت بين وصول عائقين متتاليين للاعب (بالسرعة النسبية الفعلية، ومع حساب طول العائق وطول اللاعب) لازم يكون أكبر من زمن حركة التفادي اللي يحتاجها + 0.3 ثانية. لو اللعبة مسارات: كل صف يخلي مسار مفتوح، والمسار المفتوح الجديد قريب من اللي قبله. ولو العوائق تتحرك بسرعات مختلفة، تأكد إنها ما تلحق بعض وتسكّر الطريق كله. صندوق التصادم أصغر من الرسم بحوالي 20٪.
7) حركة ثابتة على كل الأجهزة: requestAnimationFrame مع وقت بين الإطارات (delta) بالثواني ومحدود بـ 0.05، وكل السرعات بالبكسل في الثانية مو بالإطار. وقّف اللعبة لما يطلع المستخدم من الصفحة (visibilitychange).
8) الستايل: خلفية غامقة شبه سوداء، البطل والنقاط والأزرار بالذهبي #f3c766 مع توهّج نيون خفيف (shadowBlur)، وخلفية بطبقات تتحرك بسرعات مختلفة (parallax) ترسم مكان الفكرة. كل الكلام عربي من اليمين لليسار بخط النظام (system-ui, Tahoma, sans-serif)، والأزرار كبيرة للإصبع (ارتفاع 60px أو أكثر). العناوين والأرقام تتصغّر تلقائيًا (clamp مع vw) عشان ما تطلع برا الشاشة حتى على جوال عرضه 360px، والعوائق واضحة ومتباينة عن الخلفية (لا تلوّنها غامق على غامق).
9) إحساس اللعبة: اهتزاز خفيف للشاشة عند الخسارة، جزيئات صغيرة عند القفز أو كسب نقطة، وأصوات بسيطة مولّدة بـ Web Audio تبدأ بعد أول لمسة، مع زر كتم صغير بالزاوية.
10) بدون أخطاء: عرّف كل متغير قبل ما تستخدمه، وراجع الكود بنفسك قبل ما ترسله: البداية ← اللعب ← الخسارة ← العب مرة ثانية، وتأكد إن ما فيه خطأ في الكونسول.

المطلوب منك:
- اكتب الكود كامل في كتلة واحدة، بدون اختصار وبدون «...» وبدون «أكمل هنا». ولو تقدر اعرضه كـ Artifact عشان أجربه على طول.
- بعد الكود سطرين بس: كيف ألعب، وكيف أشغّلها على جوالي (احفظ الملف باسم game.html وافتحه بالمتصفح).

تأثيرات فيديو من برومبت واحد

الصقه في Claude Code داخل مجلد فاضي: يبني لك كِت موشن جرافيكس (عناوين عربية بلمعة ذهبية، أيقونات ترسم نفسها، بطاقات، انتقالات، جزيئات، زر متابعة) ويصدّر ريل 1080x1920.

أنت مصمم موشن جرافيكس ومبرمج. ابنِ لي في هذا المجلد «كِت» موشن جرافيكس قابل لإعادة الاستخدام لريلز عمودية، بـ HTML + JavaScript، ويتصدّر فيديو 1080x1920 فريم-بفريم عن طريق Chrome بدون واجهة (headless) + ffmpeg.

الهيكل المطلوب:
- lib/motion.js — مكتبة المكونات (بدون أي مكتبات خارجية).
- lib/motion.css — الألوان والخطوط والثيمات.
- lib/fonts/ — خطوط عربية مجانية (OFL) مثل Alexandria و IBM Plex Sans Arabic، حمّلها من Google Fonts وحطها محلياً.
- demo.html + demo.reel.js — ريل تجريبي 20 ثانية يستخدم كل المكونات.
- render.py — يصدّر الصور والفيديو.
- GUIDE.md — شرح مختصر بالعربي: كيف أسوي ريل جديد في 5 خطوات.

قواعد المحرك (مهمة جداً):
1. الوقت حتمي: كل شي يُحسب من دالة واحدة renderAt(t) بالثواني. ممنوع requestAnimationFrame و CSS animations و setTimeout للحركة. نفس t = نفس الصورة دائماً.
2. عرّف window.__renderAt(t) تُرجع Promise تنحل بعد ما تجهز الصور والخطوط (document.fonts.ready + decode للصور).
3. المسرح 1080x1920 ثابت، ويتصغّر في المتصفح للمعاينة فقط (scale بـ CSS). منطقة آمنة: النصوص بين y=240 و y=1680.
4. دوال تسهيل (easing) بـ cubic-bezier حقيقي: keynote (0.2,0.8,0.2,1) افتراضي، settle (0.16,1,0.3,1) للهبوط، swift (0.65,0,0.35,1) للمسح، exit (0.55,0,0.75,0.2) للخروج. ودالة ramp(t, start, duration, ease).
5. العشوائية بـ seed ثابت (مثلاً LCG) عشان الجزيئات تطلع نفسها في كل رندر.
6. العربي: dir="rtl"، والنص HTML عادي (المتصفح يشكّل الحروف صح). لا تقسم الكلمة العربية لحروف أبداً (يكسر الوصل)؛ الحركة تكون على مستوى الكلمة أو السطر.

المكونات (API بسيط وواضح):
R = Motion.reel({ dur, fps: 30, base: 'name' })
R.scene(name, t0, t1, { theme, enter: { type, d } }, s => { ... })
داخل المشهد:
1. s.title({ text: 'سطر أول|سطر فيه *الكلمة*', at, y }) — عنوان حركي: كل كلمة تطلع من تحت مع blur خفيف وتأخير 60ms بين الكلمات، والكلمة بين نجمتين تتلوّن ذهبي (#F3C766) مع «لمعة» ذهبية تمسح عليها من اليمين لليسار (linear-gradient متحرك بـ background-clip:text) بعد ما تستقر. | تعني سطر جديد.
2. s.icon({ name, at, x, y, size }) — أيقونات خطية SVG (stroke فقط، سماكة 2.5، أطراف دائرية) ترسم نفسها بـ stroke-dasharray/dashoffset خلال 0.8 ث، ثم توهج خفيف. جهّز 12 أيقونة على الأقل: prompt, code, camera, light, gamepad, check, cross, book, cube, browser, scissors, wave.
3. s.iconRow([{icon,label}...], { at, y }) — صف أيقونات بتسميات، تطلع بالتتابع.
4. s.card({ at, index, total, title, body, from: 'right' }) — بطاقة زجاجية داكنة بحواف دائرية 28px وظل ناعم، تدخل بانزلاق مع motion blur حقيقي: ارسم 6 نسخ شفافة متأخرة زمنياً (ghost trail) أو استخدم filter: blur أفقي يتناسب مع السرعة، ويختفي لما توقف. فيها رقم «١/٣» بأرقام عربية.
5. s.particles({ count: 60, at, color: 'gold' }) — جزيئات غبار ذهبي تطفو ببطء مع وميض، على canvas، حتمية بالـ seed.
6. s.counter({ from, to, at, d, suffix }) — رقم يعدّ مع تسهيل.
7. s.endCTA({ keyword, offer, reason, at, followAt }) — بطاقة النهاية: «اكتب [keyword] بالتعليقات» + سطر العرض، ثم زر «متابعة» يطلع بنبضة (scale 0.9→1.06→1) ومؤشر يد/إصبع ينزل ويضغطه فيتحول الزر لـ «تمت المتابعة ✓» بلون ذهبي، وتحته سبب المتابعة.
8. R.captions([[word, start, end], ...], { y }) — كابشن كلمة-بكلمة للريلز اللي فيها صوت، الكلمة الحالية ذهبية.

الانتقالات بين المشاهد (enter.type):
- colourSwap — المشهد الجديد يدخل بلون خلفية مختلف بمسح أفقي حاد مع انزلاق بسيط للمحتوى.
- circleWipe — دائرة تكبر من نقطة (x,y) بـ clip-path: circle() مع حافة ذهبية رفيعة تلحق الدائرة.
- zoomThrough — المشهد القديم يكبر لـ 3x ويختفي مع blur وكأن الكاميرا دخلت فيه، والجديد يطلع من 0.8x.
- cardPush — المشهد الجديد يدفع القديم لفوق كأنها بطاقات.
كل انتقال مدته d (افتراضي 0.7 ث) وبتسهيل swift.

كود Hit-stop — ليش ضربة إلدن رنق تحسّ فيها

Unreal Engine 5 — C++

هلا! هذا كود الـ Hit-stop كامل (Unreal Engine 5 - C++) 👇

// ===== Hero.h (داخل class AHero) =====
UPROPERTY() TObjectPtr<AActor> HitVictim;
FTimerHandle H;
void StartHitStop(AActor* Victim, float Seconds = 0.08f);
void EndHitStop();

// ===== Hero.cpp =====
void AHero::StartHitStop(AActor* Victim, float Seconds)
{
    HitVictim = Victim;
    CustomTimeDilation = 0.05f;                              // المهاجم (this) شبه واقف
    if (HitVictim) HitVictim->CustomTimeDilation = 0.05f;    // والعدو بعد
    // تايمر العالم ما يتأثر بـ CustomTimeDilation حق الأكتر، فـ 0.08 = 80ms فعلية
    GetWorldTimerManager().SetTimer(H, this, &AHero::EndHitStop, Seconds, false);
}

void AHero::EndHitStop()
{
    CustomTimeDilation = 1.f;
    if (HitVictim) HitVictim->CustomTimeDilation = 1.f;
    HitVictim = nullptr;
}

طريقة الاستخدام:
1) نادِ StartHitStop(TheEnemy) لحظة ما الضربة تصيب (من AnimNotify أو بعد ما تطبّق الضرر).
2) الضربة الخفيفة 0.05–0.08، الثقيلة 0.12–0.15. لو تبي تجمّد العالم كله استخدم UGameplayStatics::SetGlobalTimeDilation، بس انتبه إن التايمر بعدها يمشي بالوقت المبطّأ.

كود «العدو شافك؟»

Unreal Engine 5 — C++

هلا! هذا كود "العدو يشوفك؟" كامل (Unreal Engine 5 - C++) 👇

// ===== EnemyCharacter.h (داخل class AEnemyCharacter) =====
UPROPERTY(EditAnywhere) float SightRange = 1500.f;     // أبعد مسافة يشوف لها (سم)
UPROPERTY(EditAnywhere) float HalfAngleDeg = 35.f;     // نص زاوية المخروط
bool CanSee(const AActor* Player) const;

// ===== EnemyCharacter.cpp =====
bool AEnemyCharacter::CanSee(const AActor* Player) const
{
    if (!Player) return false;

    FVector Eye; FRotator EyeRot;
    GetActorEyesViewPoint(Eye, EyeRot);                 // مكان العين واتجاهها
    const FVector Forward   = EyeRot.Vector();
    const FVector PlayerLoc = Player->GetActorLocation();
    const FVector ToPlayer  = PlayerLoc - Eye;

    // 0) بعيد؟
    if (ToPlayer.SizeSquared() > FMath::Square(SightRange)) return false;

    // 1) داخل المخروط؟
    const float CosHalfAngle = FMath::Cos(FMath::DegreesToRadians(HalfAngleDeg));
    const float Dot = FVector::DotProduct(Forward, ToPlayer.GetSafeNormal());
    if (Dot < CosHalfAngle) return false;

    // 2) فيه جدار بالنص؟
    FCollisionQueryParams Params(SCENE_QUERY_STAT(EnemySight), false, this); // تجاهل العدو نفسه
    FHitResult Hit;
    GetWorld()->LineTraceSingleByChannel(Hit, Eye, PlayerLoc, ECC_Visibility, Params);
    return !Hit.bBlockingHit || Hit.GetActor() == Player;
}

طريقة الاستخدام:
1) نادِ CanSee(Player) كل 0.1–0.2 ثانية بتايمر (مو كل فريم) عشان الأداء.
2) لو رجعت true: العدو ينتبه (علامة "!") ويبدأ يلاحق.
3) حيلة: سوّ الـ Trace لراس اللاعب ولوسطه، لو واحد منهم واضح = شافه (ما يختفي اللاعب لو بس رجوله ورا صندوق).
4) لو تبي الجاهز: UAIPerceptionComponent + UAISenseConfig_Sight يسوي نفس الشي داخليًا.
