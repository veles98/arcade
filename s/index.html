مكتبة السكيلات

سكيلات جاهزة لـ Claude. حمّل الملف، ارفعه، وصار عندك مساعد يسوي الشغل بنفسه.

كيف أركّب السكيل؟ (3 خطوات)
  1. حمّل ملف السكيل (zip) من زر «حمّل السكيل».
  2. في Claude: Settings ← Capabilities، وشغّل Code execution and file creation.
  3. افتح claude.ai/customize/skills، اضغط Add ثم Upload skill، وارفع الملف. خلاص، يشتغل لحاله لما تطلب شي يناسبه.

يشتغل حتى بالحساب المجاني. السكيلات اللي عليها «Claude Code»: فك الضغط داخل ~/.claude/skills/. تستخدم ChatGPT أو Gemini؟ اضغط «نسخ لـ ChatGPT» والصقه في أول المحادثة.
