# سكيلز صانع المحتوى — Claude Code

14 سكل جاهزة تحوّل Claude Code إلى فريق محتوى كامل لصانع مقاطع قصيرة بالعربي: فكرة، سكربت، مونتاج، جرافيكس، صوت، غلاف، نشر، تحليل، ونمو.
كل سكل ملف `SKILL.md` فيه طريقة شغل وقوائم فحص وقوالب. عدّل اللي يناسبك (اسمك، أسلوبك، ألوانك) داخل الملفات.

## وش تسوي كل سكل

| السكل | وش تسوي |
|---|---|
| `creator-studio` | الفهرس: يختار السكل الصح وترتيب الشغل لأي فيديو |
| `content-director` | المخرج: يقرأ أرقامك وخطتك، يقترح 3 فيديوهات، يبني جدول الأسبوع، ويعترض على الأفكار الضعيفة |
| `trend-scout` | يدور الترندات ويحوّل أي ريل مرجعي إلى "مواصفات أسلوب" تقدر تعيدها |
| `video-watcher` | يشوف فيديو عام من رابط: صور من الفيديو + نص مع التوقيت + الأرقام |
| `script-writer` | سكربت بلهجة عامية لمقطع 20–90 ث: هوكات، نص الشاشة، CTA |
| `video-editor-pro` | دليل المونتاج بـ ffmpeg/Python: تقطيع، كابشن عربي، ميكس، تصدير، وقائمة فحص قبل النشر |
| `motion-designer` | عناوين عربية متحركة، أيقونات، رسوم توضيحية، بطاقة نهاية — مع تشكيل عربي صحيح |
| `sound-designer` | موسيقى ومؤثرات بتراخيص نظيفة، تنظيف الصوت، ومستويات الصوت لكل منصة |
| `thumbnail-designer` | أغلفة الريلز (مع قصّ الشبكة 3:4) وصور يوتيوب المصغّرة بعناوين عربية واضحة |
| `analytics-reviewer` | يقرأ إحصائياتك ويفسّر ليش المقطع نجح أو طاح، ويقرر الجاي |
| `community-manager` | ردود التعليقات والخاص، كلمة مفتاحية بالتعليقات ← رسالة خاصة (ManyChat) |
| `engagement-booster` | روتين 15 دقيقة يومياً، قائمة قبل/بعد النشر، ملصقات الستوري، التعاونات، مؤشرات الأداء |
| `growth-strategist` | التموضع، الجدولة، السلاسل، الربح بتوقعات صادقة |
| `originality-guard` | يمنعك تشبه غيرك أو تكتب كلام "ذكاء اصطناعي" عام قبل أي نشر |

## التثبيت

1. نزّل `creator-skills.zip` وفك الضغط.
2. انسخ مجلدات السكيلز (كل مجلد فيه `SKILL.md`) إلى:
   - ويندوز: `%USERPROFILE%\.claude\skills\`
   - ماك/لينكس: `~/.claude/skills/`
3. أعد تشغيل Claude Code. تأكد بكتابة `/skills` أو اسأله: «وش السكيلز اللي عندك؟»

النتيجة لازم تكون كذا: `~/.claude/skills/script-writer/SKILL.md` (مو مجلد داخل مجلد).

## أمثلة أوامر

```
/creator-studio عندي فكرة فيديو عن خطر استنساخ الصوت بالذكاء الاصطناعي، وش الترتيب؟
/script-writer اكتب لي سكربت 40 ثانية عن [الفكرة] مع 5 هوكات
/trend-scout هذا رابط ريل عجبني، طلّع لي مواصفات أسلوبه
/video-editor-pro ركّب voice.wav مع اللقطات في ./captures وطلّع ريل 1080x1920 مع كابشن عربي
/thumbnail-designer سوّ لي غلافين للريل بعنوان «لا تثق في الصورة»
/analytics-reviewer هذي أرقام آخر 3 ريلز: [الصق الأرقام]
/content-director خطة الأسبوع الجاي
```

## ملاحظات
- تحتاج أدوات مجانية حسب السكل: ffmpeg، Python (Pillow, numpy, faster-whisper, arabic-reshaper, python-bidi)، و yt-dlp لسكل video-watcher.
- السكيلز تكتب وتخطط وتركّب بس؛ النشر وتسجيل الدخول دايم عليك.
- الملفات اللي تذكرها السكيلز (مثل `LESSONS.md`، `analytics_log.md`، `style_library.md`) تنشأ في مجلد مشروعك أول مرة.
- مجانية للاستخدام والتعديل.
