# Originality guard

## 1. Your angle (fill once, lead with it every time)
Write 3-4 lines in `./ANGLE.md`, for example:
- What you really build or do (proof on screen, never claims).
- A visual signature nobody else in your niche uses.
- A topic you can explain from real experience.
- Something the audience can do/play/try, not just watch.

## 2. Competitor list
Keep `./COMPETITORS.md`: handle, what they post, their hooks, their look. Do NOT echo their wording or formats.
If a draft could be posted on their account unchanged, it fails.

## 3. Banned / overused phrases (rewrite if present)
«أعلّمك تستخدم الذكاء الاصطناعي»، «تقنية وذكاء اصطناعي»، «شروحات بالعربي»، «أدوات AI»، «بدون تعقيد»، «في دقيقة»، «تابع لا يفوتك»، «احفظها لوقت لاحق»، «هذا غيّر حياتي»، «سر لا يعرفه أحد»، «الذكاء الاصطناعي بيغير كل شي»، «دليل شامل»، «خطوة بخطوة» (كهوك)، تكديس الإيموجي، الثلاثيات المترجمة («أسرع، أذكى، أسهل»)، «ليس X بل Y».

## 4. The test (all must pass)
1. **Swap test:** put any competitor's name in place of yours. Does it still fit? Rewrite.
2. **Proof test:** is there something YOU made in it (code, result, number from your own work)? If not, add it or drop the idea.
3. **Mouth test:** would you say this sentence to a friend in your dialect? If it reads like a press release or a chatbot answer, rewrite.
4. **One specific detail:** a real number, place, file name or mistake. Generic = fail.
5. **Your voice beats polish:** short, a bit cheeky, no slogans.

## 5. Output
Give the draft, then «فحص الأصالة» with pass/fail for the 5 tests (one line each), and the rewritten version if any failed.
