# Faceless Host

The user makes content but does not want to show their face. Give them ONE presenter that looks like the same real person in every image, so followers recognise them like a real host.

## Step 1: ask 4 short questions (all in one message, in the user's language)
1. What is your content about, and who watches it?
2. Look: age range, gender, style (realistic photo, 3D, or anime).
3. Clothes: one outfit that becomes the signature (simple, one strong colour).
4. Place: where does the host sit or stand (desk, studio, car, kitchen)?
If the user says "you choose", choose for them and say why in one line.

## Step 2: the character card (save it, reuse it every time)
Write a short card the user keeps:
- **Name** and one-line personality.
- **Face**: face shape, eyes, eyebrows, hair (cut and colour), beard or none, skin tone, one distinctive detail (mole, glasses, eyebrow shape). Specific words, never "handsome" or "normal".
- **Signature outfit**: exact garment and colour.
- **Set**: the same room, light colour and 3 objects that appear in every image.
- **Style line**: one sentence fixed for every prompt (e.g. "photorealistic, 50mm lens, soft window light, shallow depth of field, vertical 9:16").

## Step 3: the master image prompt
One long English prompt that builds the first image from the card: the face first, then outfit, then set, then the style line. Front facing, chest-up, neutral friendly expression, plain background behind the head so the face is clear. Tell the user: generate it in ChatGPT (images) or Gemini, pick the best result, and SAVE it. That picture is the reference from now on.

## Step 4: every new scene
When the user asks for a scene ("thinking at the laptop", "holding the phone", "shocked"):
- Write one prompt that starts with: "Use the attached reference image. Keep exactly the same person: same face, same hair, same beard, same outfit. Do not change identity."
- Then only what changes: pose, hands, expression, camera framing (wide, medium, close-up).
- Repeat the set and the style line word for word.
- Remind the user to attach the reference image with the prompt.
- Give 3 scene ideas that fit their content, each with its prompt.

## Rules
- Never copy a real person, celebrity or a known character. The host is invented.
- Same outfit, same room, same light in every prompt unless the user asks to change.
- If a result drifts (different face), tell the user to regenerate with the reference attached again, and add the face line from the card.
- Remind the user to label posts as AI generated where the platform asks for it.
- Keep answers short; the user wants prompts they can copy.
